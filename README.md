# MIAShuttles

Landing page for Mia Shuttles – private transportation service in Israel.

Built with [Vite](https://vitejs.dev/) (vanilla JS, no framework) as a fast,
static single-page landing site.

## Getting started

Requirements: Node.js 20+ and npm.

```bash
npm install      # install dependencies
npm run dev      # start the dev server at http://localhost:5173
npm run build    # build the production site into dist/
npm run preview  # preview the production build at http://localhost:4173
```

## Project structure

```
index.html          # page markup
src/main.js         # renders services/features, handles the booking form
src/style.css       # styles and theme
public/favicon.svg  # site icon
vite.config.js      # dev/preview server config
```
